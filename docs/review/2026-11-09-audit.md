# Code audit — 2026-11-09

Read-only audit (ponytail-audit method) of the whole repo at commit 3f70edc. Load assumed: one person on one Mac, files up to hundreds of MB, AI agents calling `opentext-mcp` repeatedly with untrusted input. The crypto (slots, AAD, nonces, tamper tests) and the earlier security-review fixes were confirmed sound.

| # | Group | Finding | Where | Decision |
|---|---|---|---|---|
| 1 | Must | MCP `convert` accepts `overwrite: true`, so an agent can replace any same-type file without the Trash | Kit `Tools.swift` | Fix: overwrite only when trusted |
| 2 | Must | ⌘Q skips the Save / Don't Save prompt; unsaved PDF, image and unlocked-file edits are lost | App `AppDelegate`, `DocumentSession` | Fix: `applicationShouldTerminate` over all open sessions, flush text autosave |
| 3 | Must | Text save drops a UTF-8 BOM; mixed files read as Latin-1 get double-encoded once a non-Latin-1 character is typed | App `RouteSecurity.swift`, `DocumentSession` | Fix: keep BOM; confirm before switching encoding |
| 4 | Must | Open and save of big PDF, photo and text files run on the main thread | App `DocumentSession` | Fix: build bytes off the main thread; text over 20 MB opens read-only |
| 5 | Must | Highlighter restyles the whole document per keystroke; a 40 KB line of stray `*` takes 18 s | UI `TextEditorView`, `MarkdownSyntaxHighlighter` | Fix: restyle only the edited paragraph, skip huge files and lines, cheaper style key |
| 6 | Must | Locking a 300 MB file peaks at 1.5 GB of memory | Kit `Locker.swift` | Fix: remove the extra copies, stream the output, clear size limit. Chunked v2 format not done (format decision) |
| 7 | Should | Atomic saves strip Finder tags and other xattrs | App `DocumentSession` | Fix: temp file + `replaceItemAt` |

| 9 | Should | Images → PDF embeds raw pixels (1.9 MB JPEG → 14.9 MB PDF) | Kit `ImageTools.swift` | Fix: embed the source image |
| 10 | Should | Markdown → HTML keeps `javascript:` links and unescaped `"` in link targets | Kit `Markdown.swift` | Fix: escape quotes, allow only http/https/mailto/relative |
| 11 | Should | Dragging a thumbnail from another PDF window reorders this one | UI `PDFReaderView` | Fix: document id in the drag payload |
| 12 | Should | Signing a page resets its crop box to the media box | UI `PDFPageOps` | Fix: carry the crop box through, add test |
| 13 | Should | Image editor keeps unused full-size copies, rebuilds a bitmap on every redraw, resize has no cap | UI `ImageEditorView` | Fix: drop `original`, cache the image, clamp resize |
| 14 | Should | Password-protected PDF opens as a blank window | App `DocumentSession` | Fix: clear message |
| 15 | Should | Dead code and pass-through wrappers (~29 lines), `findLockedSibling` guesses the locked file | Kit, App, UI | Fix: delete; error carries the locked file's URL |
| 16 | Should | Hand-written settings comparison can silently drop a new setting | App `AppModel` | Fix: synthesized `Equatable` |
| 17 | Nice | No timeout on `textutil`, no cap on PDF render size, OCR on every page | Kit | Fix: 60 s timeout, ~100 MP render cap |
| 18 | Nice | Converting several files from Finder shows only the last result | App `AppModel` | Fix: one combined notice |
| 19 | Nice | Batch convert stops at the first error and hides files already written | Kit `Tools.swift` | Fix: per-file results with errors |
| 20 | Nice | Touch ID Keychain items can pile up across save-backs | App `LockFlow` | Won't fix now: a stable id needs a format change; logged |

Also left out by the audit and folded in where cheap: three copies of the extension tables (Kit `DocFormat`, App `FileRouting`, `URLRouter`), and MCP `create_file` creating intermediate folders anywhere.

Not checked by the audit: runtime behaviour (app never launched), MCP over stdio, HDR/wide-gamut HEIC, iCloud mtime behaviour.
