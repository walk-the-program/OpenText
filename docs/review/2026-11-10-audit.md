# Code audit (ponytail-audit), 2026-11-10

**What this repo does:** OpenText is a native macOS app for opening, editing, converting and locking documents. It ships with a CLI and an MCP server that share one conversion engine. Assumed load: one person on one Mac, files up to hundreds of MB, and AI agents calling the MCP tools with untrusted input.

**Scope:** The full audit of the 2026-11-09 tree (commit 3f70edc, report docs/review/2026-11-09-audit.md) found 20 issues, and all but one are fixed. This pass reads in depth everything that changed since then: 67 Swift files, about 5,400 lines across the button round, the Mesh redesign, the PDF tools and the self-test harness. It also re-checks the risky core paths: save, rename and PDF writing.

| # | Group | Finding | Fix | Commit |
|---|---|---|---|---|
| 1 | Must | **Clicks never reached the PDF editing code.** PDFKit's inner page view takes every click, so a signature could not be selected or moved. The self-test caught this. | `EditablePDFView.hitTest` claims clicks on editable annotations, handles and the selection | PDF-1 |
| 2 | Must | **Scrolling stopped while an annotation was selected.** Fix 1 also caught scroll-wheel events. | Only click and drag events are claimed | AUD2-1 |
| 3 | Must | **Saving any PDF built a full copy on the main thread.** Big PDFs froze the window, which undid an earlier audit fix. | The copy is built only when the PDF has signatures or text boxes; otherwise the save stays off the main thread | AUD2-1 |
| 4 | Should | **Extract parsed the whole PDF once per extracted page.** | One parse, pages moved out in the requested order | AUD2-1 |
| 5 | Should | **Rename accepted a name starting with ".",** which hides the file in Finder. | Such names are refused with a message | AUD2-1 |
| 6 | Should | **App-drawn annotations crashed on decode.** They called `fatalError` in `init(coder:)`, which any archiving path would hit. | `init(coder:)` returns nil | AUD2-1 |
| 7 | Should | **The CLI `formats` listing force-cast JSON fields** and crashed if their shape changed. | Safe casts | AUD2-1 |
| 8 | Nice | **Nine design tokens and aliases left unused by the redesign.** These were `statusBarHeight`, the old Soft Form colour aliases, `scrim`, `Motion.quick/standard/slow` and `Spacing.section`. | Deleted; the last call sites moved to the Mesh names | AUD2-1 |

Checked and fine:
- **Rename:** it never overwrites, saves first, and the window and recents follow the new name.
- **`WindowGuardDelegate`:** it holds the original delegate strongly and reinstalls itself through KVO.
- **HTML viewer:** scripts are off, every load is blocked by a content rule list, and there is no persistent store.
- **Self-test isolation:** it uses its own settings, folder and signature file, and restores window frames on exit.
- **The 400 ms Finder batching:** it is a debounce, not a guess.

Verdict: healthy after the fixes. Lean: −9 tokens or aliases, about −20 lines.
